# PATHWISE design system

## Product

PATHWISE is a calm, local-first study planning, student wellbeing and career exploration product for JEE, NEET, CET and CUET aspirants. It addresses the Design Thinking research themes of time pressure, emotional stress, rank comparison, parent communication and narrow definitions of success. Its central promise is: “Your rank is a result. It is not your identity.”

## Visual language

- Warm off-white page (#F6F7F5), white surfaces, deep evergreen text (#222B25), quiet sage accent (#668C73), and restrained clay, amber and lilac signals.
- DM Sans body text with Manrope display text; Georgia italic accents only for reflective moments.
- Generous whitespace, 9–12px card radii, subtle borders, shallow shadows, and thin chart lines.
- Avoid ranking/competition visuals, saturated gradients, childish decoration, diagnosis language and surveillance metaphors.
- Motion is limited to short transitions and progress feedback. Respect reduced-motion preferences.

## Product shell

Desktop uses a persistent 236px left navigation and a sticky compact top bar. Mobile uses an off-canvas navigation menu with a scrim. Student and parent modes share the shell but present different data and intent. Dashboard cards emphasize readiness, consistency and a sustainable daily path.

## Core flows

Landing → Student dashboard → Plan → Study → Check-in → Progress → Explore careers → Define success. Parent view offers high-level shared trends and conversation prompts, never a minute-by-minute activity log.

## Components and interaction

Use semantic buttons and labeled controls, visible focus rings, readable contrast, responsive grids and local storage. Charts are native SVG/CSS, with labels and explanatory copy. Every action returns visible feedback. Local sample content must be clearly fictional and non-diagnostic.
