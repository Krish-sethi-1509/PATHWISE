# PATHWISE

PATHWISE is a local-first preparation and wellbeing companion for entrance-exam aspirants. It is a frontend demonstration built with React, TypeScript and Vite; it uses fictional sample data and stores personal choices in the browser's local storage.

## Run locally

```sh
npm install
npm run dev
```

Use the landing page to enter the student workspace. The sidebar switches between the student and parent experiences. Planner preferences, task completion, check-ins, career interests, the Rank Detox setting and the success profile are saved in this browser.

## Build

```sh
npm run build
npm run preview
```

No API key or backend is required. Career pathway information is illustrative; students should confirm routes and eligibility with the relevant institution.
